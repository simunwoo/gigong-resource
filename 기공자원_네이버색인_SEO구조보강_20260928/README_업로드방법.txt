기공자원 GitHub Pages SEO 최종수정본

핵심 수정:
- 네이버 경고 대응: meta description 80자 이내로 축약
- title / description / Open Graph / Twitter 메타 정합성 통일
- canonical 및 OG URL을 기공자원.kr 퓨니코드 기준으로 통일
- LocalBusiness JSON-LD 정리 및 미확인 alternateName 제거
- 실제 og-image.jpg, favicon, webmanifest 생성
- robots.txt / sitemap.xml 재점검
- 기존 본문 디자인과 레이아웃은 유지

GitHub 저장소 루트에 이 패키지의 파일/폴더를 업로드하여 기존 파일을 교체하세요.
